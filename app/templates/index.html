    From raw echoes to a deployed model

    1. Clean

      Audited {{ meta.data.before_cleaning.n_rows }} rows for missing values, duplicates, out-of-range energies and invalid labels. Outliers were kept: every value is a physically valid echo.

    2. Split

      Stratified 80 / 20 split ({{ meta.data.split.train_rows }} train, {{ meta.data.split.test_rows }} test) so both sets keep the 53 / 47 mine-to-rock ratio.

    3. Train and tune

      Scaling sits inside each pipeline, fitted only on training folds. Grid search picks hyper-parameters; 50-fold repeated CV measures stability.

    4. Deploy

      A Flask API serves the saved models to this page, which works on phones, tablets and desktops and can be installed as an app.
